# ✈️ Hero Travel 🌍

**Hero Travel** হলো একটি সাধারণ **HTML এবং CSS** ব্যবহার করে তৈরি করা **Travel & Tour** ওয়েবসাইট। এখানে ব্যবহারকারীরা জনপ্রিয় ট্যুর, গন্তব্য, অফার এবং ডিসকাউন্ট সম্পর্কিত তথ্য দেখতে পারবেন। সাইটটি মোবাইল এবং বড় ডিভাইস উভয়ের জন্যই **responsive design** এ তৈরি করা হয়েছে।

## 📂 Project Features  

- 🌅 Attractive **Hero Section** with search options (Where, When, Type).  
- 🏔️ **Popular Tours** showcase with image & description.  
- 🌍 **Choose Destination** gallery (Maldives, Indonesia, Sri Lanka, North America, Kashmir, Bangladesh, Bandarban).  
- ⭐ **Why Choose Us** section with multiple highlights.  
- 💸 **Deals & Discount** with pricing and booking button.  
- 📽️ Section with video and image preview.  
- 📰 Newsletter subscription form.  
- 📱 **Fully Mobile Responsive** design.  

---

## 📌 Notes  

- This is a **practice project** built with only **HTML & CSS**.  
- Responsive design for both mobile and large devices.  
- No backend or database.
